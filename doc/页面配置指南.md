# 桌面信息屏 · 页面配置与使用指南

本设备是基于 ESP8266 + ST7789（240×240）的桌面信息屏，共 12 个页面轮流显示。
本文介绍**每个页面需要配置什么、在哪里配置、如何使用**，以及需要从电脑推送数据的页面怎么接。

> ⚠️ **重要：屏幕字体只支持 ASCII（英文/数字/符号）。** 天气、新闻、消息、股票名等内容请使用**英文或拼音**；中文会显示成方框乱码（项目内虽有中文点阵字库，但当前固件未接入任何页面）。

---

## 一、连接设备与打开配置页

所有配置都在设备自带的网页里完成，改完点 **“保存并重启”**，约 5 秒后新配置生效。

| 场景                       | 如何访问配置页                                               |
| -------------------------- | ------------------------------------------------------------ |
| **首次使用 / 连不上 WiFi** | 设备开放热点 **`InfoDisplay-XXXX`**（无密码）。手机/电脑连上后，浏览器打开 **`http://192.168.4.1`**（一般会自动弹出配网页）。先在“网络”卡片里填好 WiFi 名/密码，保存重启。 |
| **已联网（推荐）**         | 浏览器打开 **`http://infodisplay.local/`**（主机名可在“网络→主机名”里改）。若 `.local` 解析不了，就用设备 IP（在**系统**页或配置页顶栏能看到）。 |

其他说明：

- **敏感字段留空 = 不修改**：WiFi 密码、HA 令牌回读时是空的，不想改就留空，保存不会清空原值。
- **时区**：在“系统”卡片选择（默认 UTC+8）。**背光**开关也在这里。
- **固件升级（OTA）**：配置页底部“固件升级”卡片，选 `.bin` 上传即可，升级中勿断电。
- **配置文件**：全部持久化在设备的 `/config.json`；网页保存即写入并重启。

## 二、页面开关、顺序与切换方式

在配置页的 **“切换方式”** 卡片里统一设置。先选一种切换模式：

### 1. 定时轮播（默认）

选中后下方展开 **“页面”** 列表，逐页设置：

- **开关**：是否显示该页（关掉则跳过）；
- **↑ / ↓**：调整轮播顺序；
- **秒数**：该页停留多久后切换到下一页。

12 个页面 id：`weather 天气 / stock 股票 / home 米家 / message 消息 / system 系统 / pet 萌宠 / news 新闻 / pc 电脑 / clock 时钟 / gpu 显卡 / train 训练 / overview 概览`。

### 2. 体感（朝向 + 手势）

用板载 MPU6500 加速度计翻页，选中后展开体感映射：

- **朝向 → 页面**：把 6 个静止朝向（朝上/朝下/左/右/顶/底）各映射到一个页面。设备**持续保持**某朝向时，就锁定显示对应页。
- **手势 → 页面**：把 4 个手势（向左甩/向右甩/双击/摇一摇）各映射到一个页面。手势触发后**跳到对应页并停留“手势停留秒数”**，到期再退回“按当前朝向显示”——以此避免手势和朝向互相打架。
- 选 **“（不切换）”** 表示该动作不翻页；只有在“定时轮播→页面”里**已启用**的页才能被选中生效。
- **当前朝向没有映射时**，会按各页停留时长自动轮播兜底（永远不会卡死在一页）。
- **朝向校准**：朝向的物理含义取决于设备怎么摆放。接上串口（115200）看日志里的 `face=FaceUp/Left/...`，边翻转边观察，确认每个物理姿势对应的名字后再去网页映射。

> 页面的“启用/顺序/停留时长”始终在“定时轮播”下设置；体感模式也会用到这份启用列表作为可切换的页面池。

## 三、需要联网 API 的页面

### 🌤 weather（天气）

| 配置项  | 网页位置                | 说明                                                         |
| ------- | ----------------------- | ------------------------------------------------------------ |
| API Key | 天气 → 心知天气 API Key | 到 **心知天气 seniverse.com** 免费注册获取                   |
| 城市    | 天气 → 城市             | 请求带 `language=en`，**建议用拼音或城市 ID**（如 `beijing`、`shanghai`） |

- 数据源：心知天气 `api.seniverse.com`（实况 + 未来 3 天）。
- 显示：大时钟/日期、当前温度与天气图标、底部三天预报。约 **30 分钟**刷新。

### 📈 stock（股票）

| 配置项   | 网页位置        | 说明                                                         |
| -------- | --------------- | ------------------------------------------------------------ |
| 代码列表 | 股票 → 代码列表 | 腾讯行情代码，**带 `sh`/`sz` 前缀，逗号分隔，最多 16 个**。例：`sh000001,sz399001,sz399006,sh600519` |
| 指数个数 | 股票 → 指数个数 | 前 N 个作为“指数”固定显示在上方，其余进入底部跑马灯          |
| 概览代码 | 股票 → 概览代码 | 供**概览页**用的**单只**代码（本页不用），如 `sh600519`      |

- 数据源：腾讯行情 `qt.gtimg.cn`，**免费、无需 key**。约 **60 秒**刷新。
- 已知别名：`sh000001→SH`、`sz399001→SZ`、`sz399006→CY`、`sh000300→HS300`，其余去掉前缀显示。

### 🏠 home（米家 / Home Assistant）

本页通过 Home Assistant 的 REST API 读取传感器与设备状态。

| 配置项          | 网页位置                   | 说明                                                         |
| --------------- | -------------------------- | ------------------------------------------------------------ |
| HA 地址         | 米家(HA) → HA 地址         | 如 `http://192.168.1.20:8123`，**结尾不要加斜杠**            |
| 长期访问令牌    | 米家(HA) → 长期访问令牌    | HA 里：**个人资料 → 长期访问令牌 → 创建令牌**                |
| 温度/湿度/PM2.5 | 米家(HA) → 温度/湿度/PM2.5 | 传感器实体 id，如 `sensor.xxx_temperature`                   |
| 净化器/灯/电视  | 米家(HA) → 净化器/灯/电视  | 开关类实体 id，如 `fan.xxx` / `light.xxx` / `media_player.xxx` |

- 实体 id 在 HA 的 **开发者工具 → 状态** 里查。留空的实体会跳过不显示。
- 读取方式：`GET <HA地址>/api/states/<实体id>`，带 `Authorization: Bearer <令牌>`，只取 `state`。约 **30 秒**刷新。
- 开关态判断：`off/unavailable/unknown/standby/idle/空` 视为关，其余为开。

- 可以参考和使用如下测试脚本

```shell
python3 scripts/ha_mock.py
```

### 💬 message（消息，MQTT）

把手机/服务器的消息通过 MQTT 推到屏上。

| 配置项       | 网页位置            | 说明                                                         |
| ------------ | ------------------- | ------------------------------------------------------------ |
| Broker       | 消息(MQTT) → Broker | MQTT 服务器域名，如 `broker.emqx.io`                         |
| 端口         | 消息(MQTT) → 端口   | 默认 `1883`（明文）                                          |
| 主题 (Topic) | 消息(MQTT) → 主题   | **务必改成你自己的唯一字符串**，避免和别人撞车，在配置网页中改 |

- 发消息：用任意 MQTT 客户端（`mosquitto_pub`、MQTTX、各类手机 App）向**同一个 broker + topic** 发布即可。设备后台常驻订阅（断线每 5 秒自动重连）。

- payload 支持两种：

  - **纯文本**：直接作为正文。
  - **JSON**：`{"title":"标题","body":"正文","level":"info"}`（`body` 也可写 `text`）。`level` 影响强调色：`alert`/`error`→红，`warn`/`warning`→黄，其余（`info`）→青。

- 例（mosquitto）：

  ```bash
  mosquitto_pub -h broker.emqx.io -t "st7789-inbox/你的唯一串/msg" \
    -m '{"title":"Build","body":"deploy ok","level":"info"}'
  ```

- ⚠️ 正文用 ASCII 字体绘制，**请发英文**。

### 📰 news（新闻，RSS）

| 配置项   | 网页位置        | 说明                                                         |
| -------- | --------------- | ------------------------------------------------------------ |
| RSS 地址 | 新闻 → RSS 地址 | 建议**英文 RSS 源**，如 `http://feeds.bbci.co.uk/news/world/rss.xml` |
| 来源名称 | 新闻 → 来源名称 | 仅用于右下角显示，如 `BBC`                                   |

- 只抓取标题（最多 8 条），会**过滤掉非 ASCII 字符**，所以中文源基本不可读。约 **15 分钟**刷新。

### 🧭 overview（概览）

一屏四格：时间 / 天气 / 一只自选股 / GPU 占用。

- **无独立配置**，复用：天气的 `key`+`城市`、股票的 `概览代码`；GPU 那格需要 `gpu` 页有数据推送（见下）。

## 四、需要从电脑推送数据的页面（局域网 HTTP POST）

`pc`、`gpu`、`train` 三个页面的数据不是设备自己抓的，而是由你电脑上的程序通过局域网 **HTTP POST（JSON）** 推送过来。三个端点都在 **80 端口**，成功返回 `200 ok`。设备没收到数据时，屏上会提示要 POST 的地址（形如 `POST to http://<设备IP>/pc`）。

> 下面命令里的 `infodisplay.local` 都可以换成设备 IP。

### 💻 pc（电脑状态） + 🎮 gpu（显卡）—— 用配套脚本一键推送

推荐直接用仓库里的 **`scripts/pc_agent.py`**：它每秒采集 CPU/内存/音量/网速推给 `/pc`；若有 NVIDIA 显卡，再把利用率/显存/温度/功耗推给 `/gpu`。

**依赖安装：**

```bash
pip install psutil requests
# Windows 想读系统音量，额外装： pip install pycaw comtypes
# Linux 想读音量：            sudo apt-get install pulseaudio-utils   # 提供 pactl
# 想推 GPU：需已装 NVIDIA 驱动（命令行能跑 nvidia-smi）
```

**运行：**

```bash
# 1) 编辑 scripts/pc_agent.py，把顶部 ESP_IP 改成你设备的 IP
# 2) 运行
python scripts/pc_agent.py
```

**字段说明（也可用其它语言/工具自行 POST）：**

`POST /pc`（全部可选，缺哪个就保留上次的值）：

| 字段   | 类型 | 含义                                            |
| ------ | ---- | ----------------------------------------------- |
| `cpu`  | 整数 | CPU 占用 %                                      |
| `ram`  | 整数 | 内存占用 %                                      |
| `vol`  | 整数 | 系统音量 %（取不到给 -1）                       |
| `down` | 数值 | 下行网速（单位固定按 **M/s** 显示，内置于固件） |
| `up`   | 数值 | 上行网速                                        |

`POST /gpu`：

| 字段       | 类型   | 含义            |
| ---------- | ------ | --------------- |
| `util`     | 整数   | GPU 利用率 %    |
| `memUsed`  | 整数   | 已用显存 **MB** |
| `memTotal` | 整数   | 显存总量 **MB** |
| `temp`     | 整数   | 温度 ℃          |
| `power`    | 整数   | 功耗 W          |
| `name`     | 字符串 | 显卡名（英文）  |

**手动测试（curl）：**

```bash
curl -X POST http://infodisplay.local/pc  -H "Content-Type: application/json" \
  -d '{"cpu":42,"ram":68,"vol":60,"down":12.3,"up":1.1}'

curl -X POST http://infodisplay.local/gpu -H "Content-Type: application/json" \
  -d '{"util":42,"memUsed":6200,"memTotal":16376,"temp":62,"power":85,"name":"RTX 4070"}'
```

- 超过 **8 秒**没收到数据，对应页会显示 “offline”。

### 🧪 train（训练进度）—— 深度学习训练监控

有两种用法：

**A. 训练循环里实时上报（`scripts/train_report.py`）**

```python
# pip install requests；先把 train_report.py 顶部 ESP_IP 改成设备 IP
from train_report import report

for epoch in range(EPOCHS):
    for step, batch in enumerate(loader):
        loss = train_step(batch)
        if step % 20 == 0:                        # 别推太频繁
            report(name="resnet50", status="training",
                   epoch=epoch+1, epochs=EPOCHS,
                   step=step+1, steps=len(loader),
                   loss=float(loss), acc=None, eta="")
report(name="resnet50", status="done",
       epoch=EPOCHS, epochs=EPOCHS, loss=float(loss), acc=0.93)
```

`report(...)` 是非阻塞的，推送失败会静默忽略、不影响训练。

**B. 造假数据验证显示效果（`scripts/train_sim.py`）**

```bash
python scripts/train_sim.py                                  # 默认 300 epoch
python scripts/train_sim.py --host infodisplay.local --name job-b --epochs 1200 --delay 0.02
```

loss 会从 ~2.5 指数衰减到 ~0.01，可用来检查曲线（跨量级时自动切对数纵轴）和防闪烁。

**`POST /train` 字段：**

| 字段               | 类型   | 含义                                                        |
| ------------------ | ------ | ----------------------------------------------------------- |
| `name`             | 字符串 | 任务名（**换名字或 epoch 回退会清空历史曲线**，视为新一轮） |
| `status`           | 字符串 | 状态，如 `training` / `done`                                |
| `eta`              | 字符串 | 预计剩余，如 `1h23m`                                        |
| `epoch` / `epochs` | 整数   | 当前 / 总 epoch                                             |
| `step` / `steps`   | 整数   | 当前 / 每 epoch 总 step                                     |
| `loss`             | 浮点   | 损失                                                        |
| `acc`              | 浮点   | 准确率 **0..1**（显示为 %）                                 |

**手动测试（curl）：**

```bash
curl -X POST http://infodisplay.local/train -H "Content-Type: application/json" \
  -d '{"name":"resnet50","status":"training","epoch":3,"epochs":100,"step":1200,"steps":5000,"loss":0.0234,"acc":0.91,"eta":"1h23m"}'
```

- 超过 **20 秒**没收到数据显示 “offline”；显示 loss 趋势曲线，epoch 很多时自动抽稀、内存恒定。

## 六、config.json 结构速览（进阶）

网页保存后会写入设备 `/config.json`，结构大致如下（敏感字段回读为空）：

```json
{
  "net":   { "ssid": "", "pass": "", "host": "infodisplay" },
  "weather": { "key": "", "loc": "beijing" },
  "stock": { "symbols": "sh000001,sz399001", "overview": "sh600519", "indexCount": 3 },
  "ha":    { "url": "http://192.168.1.20:8123", "token": "",
             "temp": "sensor.x_temperature", "humi": "sensor.x_humidity",
             "pm25": "sensor.x_pm2_5", "fan": "fan.x", "light": "light.x", "tv": "media_player.x" },
  "mqtt":  { "broker": "broker.emqx.io", "topic": "st7789-inbox/your-id/msg", "port": 1883 },
  "news":  { "feed": "http://feeds.bbci.co.uk/news/world/rss.xml", "source": "BBC" },
  "sys":   { "tzOffset": 28800, "backlight": true },
  "pages": [ { "id": "weather", "en": true, "dwell": 8 }, ... ],
  "sw": {
    "mode": "auto",                     // auto=定时轮播, orient=体感
    "holdS": 5,                          // 手势触发后停留秒数
    "faces":    { "up": "", "down": "", "left": "", "right": "", "top": "", "bottom": "" },
    "gestures": { "swipeLeft": "", "swipeRight": "", "doubleTap": "", "shake": "" }
  }
}
```

- `tzOffset` 单位是**秒**（东八区 = 28800）。
- `pages[]` 的顺序即显示顺序，`dwell` 单位秒。
- `sw.faces` / `sw.gestures` 的值是**页面 id**（空串=不映射）。

> 修改配置一律通过网页并重启生效；而 `pc`/`gpu`/`train`/`message` 的数据是运行时推送的，**无需重启**。
